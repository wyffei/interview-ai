# 语音面试助手

> 听面试官说话，结合你的简历和复盘库，实时给出回答提示。

本项目 fork 自 [ooboqoo/interview-coder-cn](https://github.com/ooboqoo/interview-coder-cn)，专注语音面试：听对方说话实时出提示，并新增「复盘库按题检索」。

## 它做什么

- **听**：采集系统音频（会议里对方的声音），用阿里云百炼 Fun-ASR 实时识别，对方说完一句就出提示
- **查**：先在你的复盘库里按问题查找。有现成回答直接显示原文，不等 AI；问法相近就让 AI 按这次的问法改写；没准备过就把最相关的几条连同简历交给 AI 生成
- **答**：提示是一句能直接说出口的开场，加上几个要点；经历类问题按 STAR 给出

## 快速开始

### 1. 安装依赖并运行

项目运行依赖 [Node.js](https://nodejs.org/zh-cn/download)（LTS 版本）。

```bash
$ npm install
$ npm run dev
```

### 2. 配置 AI

「设置 → AI 模型」里填写 `API Base URL`、`API Key` 和模型。任何兼容 OpenAI API 的平台都可以，如 DeepSeek、[硅基流动](https://cloud.siliconflow.cn/)、[OpenRouter](https://openrouter.ai/)。**建议打开「关闭思考」**：面试提示最在乎首字延迟。

> 部分平台或网关除了 API Key 还要求额外的请求头，可以在配置的「高级 → 自定义请求头」里每行填一个 `名称: 值`。

### 3. 配置语音识别

在[百炼平台控制台](https://help.aliyun.com/zh/model-studio/get-api-key)创建 API Key，填到「设置 → 语音」。Fun-ASR 实时模型约 0.02 元/分钟，以百炼官网为准。

### 4. 导入简历和复盘库

在「设置 → 资料库」导入：

- **简历**：选「整份发送」，每次请求都会带上
- **复盘库 / 题库**：选「按题检索」（超过 8000 字的资料导入时默认就是），只把和问题相关的几条发给 AI

复盘库用 Word 的「标题 1/2/3」样式标出每道题，标题下面的正文就是答案。另外，「Q1：…」开头的行、以问号结尾的加粗短句、`问题？ | 答案` 的表格行也会各自成为一道题。导入后资料库里会显示「切成 N 条」，条数明显偏少说明标题没识别出来。

### 5. 开始监听

按 `⌥ T`（Windows 为 `Ctrl+T`）开始监听，对方说完一句话，右侧就会出提示。卡片上会标明来源：

| 标记              | 含义                                                     |
| ----------------- | -------------------------------------------------------- |
| 复盘库原文        | 复盘库里有这道题，直接显示你准备的回答，不调用 AI        |
| 按复盘库改写      | 问法相近，或同一道题准备过几个版本（如每家公司一版的自我介绍），AI 按这次的问法改写 |
| 参考复盘库 N 条   | 没准备过这道题，AI 参考最相关的 N 条和简历生成           |

## 出提示的方式

- **自动**（默认）：对方说完一句话立刻出提示。如果对方其实还没说完，这条提示会先撤回，等说完后重写到同一张卡里；「好的」「嗯」这类太短的句子不会触发
- **手动**：只在按「出提示」快捷键时出
- 随时可以按「出提示」立即出；没有新内容时再按一次，会把上一条换个说法重出（复盘库原文也会换成 AI 的说法）
- 「说完判定」的停顿时长和触发字数可以在「设置 → 出提示 → 高级」里调整
- 想复盘的话，打开「设置 → 出提示 → 保存对话记录到本地」，对话和提示会保存成 Markdown 文件（默认在 文档/InterviewCoder）

## 常用快捷键

| 操作                  | macOS  | Windows        |
| --------------------- | ------ | -------------- |
| 开始 / 停止监听       | `⌥ T`  | `Ctrl+T`       |
| 出提示                | `⌥ G`  | `Ctrl+G`       |
| 切换自动 / 手动       | `⌥⇧ G` | `Ctrl+Shift+G` |
| 停止生成              | `⌥ .`  | `Ctrl+.`       |
| 清空对话              | `⌥⇧ T` | `Ctrl+Shift+T` |
| 隐藏 / 显示窗口       | `⌥ H`  | `Ctrl+H`       |
| 鼠标穿透              | `⌥ M`  | `Ctrl+M`       |

所有快捷键都可以在「设置 → 快捷键」里修改，完整列表见应用内的「帮助中心」。

## 遇到问题

先看提示卡片上的「生成失败：……」报错原文。AI 配置相关的常见问题可以参考上游的 Wiki：[AI 模型配置与调用失败](https://github.com/ooboqoo/interview-coder-cn/wiki/AI%E6%A8%A1%E5%9E%8B%E9%85%8D%E7%BD%AE%E4%B8%8E%E8%B0%83%E7%94%A8%E5%A4%B1%E8%B4%A5)、[语音与对话模式](https://github.com/ooboqoo/interview-coder-cn/wiki/%E8%AF%AD%E9%9F%B3%E4%B8%8E%E5%AF%B9%E8%AF%9D%E6%A8%A1%E5%BC%8F)。

## 打包

```bash
$ npm run build:win   # Windows
$ npm run build:mac   # macOS
```

也可以在项目根目录创建 `.env` 文件预配置 AI 平台，程序启动后会自动读取作为默认值：

```env
API_BASE_URL="https://api.deepseek.com"
API_KEY="sk-1234567890" # 这里只是示例
MODEL="deepseek-flash"  # 可选
```

## 关于隐身能力的说明
