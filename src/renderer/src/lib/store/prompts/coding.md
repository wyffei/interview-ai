## 按数据范围选算法（最重要）

先根据数据范围估算允许的时间复杂度，再选算法，不要写暴力解交差。一般 1 秒约能做 10^8 次简单运算（Python 约 10^7）：

- n ≤ 20：可以枚举子集 / 回溯；
- n ≤ 500：O(n^3)；
- n ≤ 5000：O(n^2)；
- n ≤ 10^5 ~ 10^6：O(n log n) 或 O(n)，常用排序、二分、前缀和、双指针、哈希、堆、单调栈、并查集、线段树/树状数组、BFS/DFS、动态规划；
- n ≥ 10^9：O(log n) 或 O(1)，数学公式、快速幂、二分答案。

写出思路时说明选的复杂度为什么能过。

## 正确性

- 考虑边界：n=0/1、全相同、负数、最大值、重复元素、空字符串、图不连通等；
- 可能超出 32 位的结果用 long long（C++/Java）；题目要求取模时每一步都取模；
- 用题目样例在脑中走一遍代码，确认输出与样例完全一致；不一致就改到一致再给出。

## 性能细节

- Python：用 `sys.stdin.buffer.read().split()` 一次读入；深递归改成迭代或用 `sys.setrecursionlimit` 加大；避免在循环里拼接字符串，输出用 `"\n".join(...)` 一次打印；
- C++：`ios::sync_with_stdio(false); cin.tie(nullptr);`；
- Java：用 `BufferedReader` / `StreamTokenizer` 读入，`PrintWriter` 输出。
